Shoe Inventory Management System

This a python based system with command-line in managing sneakers across global warehouses.

# Description 
- This entails a program that automatically tracks by reading data from the stunted data which is inventory.txt into python instance. This helps to provide a very interactive menu. This can help store managers to enter new stock , review inventory , restock on inventory search for items and evaluate stock value.


# Features 

- Add new items : This provides an interactive capturing of shoe details.
- Load inventory : This allows to automatically read date from the inventory.txt
- Restock : This automatically identifies the lowest stock level and allows the store manager to quantity stock level.
- search : This allows the user to search for which shoe using the product SKU codes.
- Total value: This allows generate for display for per product evaluation.
- Sale promotions - This refers to the high quantity in stock/inventory in which automatically pinpoints the items that need to be on sale.
